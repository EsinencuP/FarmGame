# P0-4 — HUD и предпросмотр строительства

21 октября 2026 · Unity 6000.6.4f1 · Prototype.

P0-4 выполнен. В конце работы пользователь уточнил порядок проверок: автоматические тесты запускаются только при закрытии крупных фаз Phase 0 / Phase 1 / Phase 2 и далее. Правило записано в корневой [AGENTS.md](../../AGENTS.md), roadmap и AI-контексте. После этого указания новые прогоны не запускались.

## Изменения

- `ResponsiveHudLayout` использует `[ExecuteAlways]`, иллюстративные данные и три режима Inspector: Exploration, BuildAllowed, BuildBlocked. OnValidate планирует обновление layout; preview не вызывает runtime-инициализацию, BuildPrototype или сохранения. На живых играющих объектах переключатель Editor preview не применяется.
- `BuildPromptUI` — отдельный сохранённый элемент `Prototype HUD/Build Prompt`. Высота фиксирована: **180 canvas units**, поле текста 156. Общая подсказка взаимодействия остаётся отдельным элементом высотой 56. При строительстве она скрывается; после отмены возвращается. Общая памятка управления скрывается на время строительной карточки.
- Пять строк содержат выбранную постройку/цену/размер, каталог 1–5, результат проверки места, **E / ЛКМ — подтвердить**, **Q / R — повернуть**, **Esc / ПКМ — отмена**, а также M, Delete и B. Один форматтер формирует одинаковые строки для Editor preview и игры.
- Q и R действительно вращают постройку. В строительном режиме клавиатурный поворот камеры заблокирован, поэтому Q не выполняет два действия. Орбита мышью и zoom сохранены. Подтверждение удаления принимает E/Enter; случайный клик его не подтверждает.
- Полупрозрачный силуэт использует реальные метрические prefab всех пяти построек. `MyLittleFarm/BuildingGhost` имеет alpha 0.35, Transparent queue, SrcAlpha blending, ZWrite Off. Материал заменён во **всех слотах** каждого renderer, включая части многоматериальных моделей. Нет физических препятствий от preview, теней или перехвата выбора. Зелёный/красный footprint и маркер фасада сохранены.
- Материалы силуэта создаются один раз на настройку системы и освобождаются при перенастройке/уничтожении. Перенос/поворот используют тот же prefab и масштаб, что у итоговой постройки.

Сохранённая сцена обновлена через `Editor/HudConsistencySetup.cs`; карта и игровые системы не пересоздавались. Повторная установка: **Tools → My Little Farm → Apply P0-4 HUD And Build Preview**. Обычный bake создаёт отдельную карточку, а MVP upgrade подключает новый layout и shader reference. Пользовательские сохранения не читались и не записывались.

## Визуальная проверка

Захвачены обычный HUD, разрешённое/запрещённое строительство и Edit Mode preview при **1280×720, 1920×1080, 2560×1440, 1280×800**. Все пять строк помещаются: фактическая требуемая высота текста около 112–114 при доступных 156 units.

Снимки точных разрешений получены в временной копии Prototype через существующую камеру и Canvas; только для захвата Canvas временно переключался из Overlay в ScreenSpaceCamera с тем же CanvasScaler масштабом. Код и восстановление параметров: [CaptureHud.cs.txt](CaptureHud.cs.txt). Отдельно сохранены нативные Game View кадры **1728×743**, включая Overlay UI. Копия сцены имела отдельное имя, исключающее автозагрузку/автосохранение Prototype. После проверки исходная Prototype открыта вне Play Mode, временная сцена удалена.
