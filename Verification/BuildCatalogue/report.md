# Каталог строительства — 13.11.2026

Обновлены сохранённые карточки Prototype: первая страница содержит дом, склад, рынок, клумбу, курятник, яблочный пресс, кормушку, мельницу, сыроварню и коровник с загоном. Названия, цены, размеры и иконки соответствуют BuildingDefinition.Catalog. Остальные 30 декоративных объектов остаются на следующих страницах.

BuildCustomizationUI обновляет карточки при включении и входе в строительство, а также при открытии/перелистывании. Есть явный Refresh Construction Catalogue для авторинга; общий установщик FarmUISetup вызывает тот же метод. Карточки не образуют отдельный устаревающий список построек. Выбор скрытого/несуществующего слота отклоняется.

В Prototype на диске изменены только поля текста десяти карточек и пять иконок. Полная перезапись сцены не выполнялась; прежние несохранённые изменения открытой сцены сохранены в памяти и отдельной локальной копии CatalogueSourceBackup.

Компиляция прошла, ошибок Console нет. Короткая ручная проверка выполнена на отдельной CatalogueReview без slot persistence: открытие видимого каталога, выбор кнопками всех пяти новых типов (apple_press, feeder, mill, cheese_dairy, barn), закрытие панели после выбора, переход к декору и обратно. Выбранная мельница размещена в (2,2); баланс 1000→920, paidCost=80. [Наблюдения](manual-observations.json), [кадр 1366×768](catalogue-1366.png).

Начальный малый кадр catalogue-page-one.png и поле open.modal сами по себе не подтверждают видимость: изолированная сцена сначала сохраняла modal-флаг вне штатного маршрута стартового меню. После сброса состояния проверки показана видимая панель; visibleSelection фиксирует видимость до каждого из пяти нажатий. Правки логики показа из-за этого диагностического состояния не потребовались.

Автотесты и Verify-Scripts не запускались согласно AGENTS.md; полная приёмка остаётся на U1-8. Пользовательские фермы не использовались как данные проверки. Временная review-сцена удаляется после выхода из Play Mode, исходная сцена остаётся в Edit Mode с прежним dirty-состоянием.
