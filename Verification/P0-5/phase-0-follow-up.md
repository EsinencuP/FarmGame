# Проверки при закрытии Phase 0

P0-5: автоматические тесты в этом пункте не запускаются, согласно AGENTS.md. При финальном закрытии Phase 0 дополнить регрессию следующими случаями:

- Курицу, яблоню и обе торговые точки выбирает отдельный FarmInteraction raycast; земля под целью не подсвечивается, посторонние Default-коллайдеры не вытесняют pick volume из объектного прохода.
- Переход объекта через границу клеток при сохранённом hover не сбрасывает dwell. Между разными курицами/клетками dwell сбрасывается.
- Однокадровый промах на границе цели не меняет текст на землю/nearby fallback. После устойчивого ухода текст обновляется; во время переключения действие E/ЛКМ блокируется.
- Деактивированная/уничтоженная цель снимает outline; выход из карты и вход в строительство очищают оба вида выделения.
- Повторный Configure pick volume не создаёт дубликаты. Поворот/масштаб родителя не сдвигает локальный объём выбора.
- Tree target без Orchard state не обрабатывает землю. Клик вне карты не продаёт/не кормит ближайшую цель; проверки дальности остаются прежними.
- Существующие GameplayReviewRegressionTests, MvpReliabilityTests, BuildingIntegrationTests и весь suite выполняются вместе со всеми изменениями Phase 0.
