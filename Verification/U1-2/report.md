# U1-2 — груша

Реализовано 12.11.2026. U1 остаётся открытой; итоговая приёмка фазы не выполнена.

## Результат

- OrchardSystem выбирает TreeDefinition из реестра вместо единственной яблони. Старые ID apple/apple_tree допустимы. Яблоня остаётся бесплатной, с урожаем 3 яблока через 30 секунд, затем каждые 45 секунд.
- Груша: саженец 30 монет, первый урожай 45 реальных секунд, последующие 60, по 3 плода. Цена продажи 24 монеты за плод. ID pear и pear_sapling.
- В инвентаре доступны бесплатный выбор яблони и принадлежащие игроку саженцы груши; покупка саженцев — категория «Семена и сад» на рынке. Посадка использует прежнюю переназначаемую команду (по умолчанию T). Сохранённые пользователем клавиши не менялись.
- Подсказки, описание товара/предмета, продажа и справочник читают выбранное определение. Крона груши выше и уже яблоневой, зрелые плоды золотистые с коричневым черенком. Исходные импортированные модели не изменялись.
- Сохранения v14 добавляют selectedTreeId. Вид и два UTC-поля каждого дерева остаются независимыми. Старые версии выбирают яблоню. Сбор фиксирует таймер до событий инвентаря; повторный вход заблокирован.

## Изоляция и исходная сцена

Изначальная Prototype содержала несохранённые изменения. При первом переходе диагностическая защита отказала, но последовавшая команда Play ошибочно запустила исходную сцену; запуск сразу остановлен, игровых действий не выполнялось. Метаданные файлов пользовательских сохранений показывали даты до начала задачи (user-save-metadata.json); содержимое этих файлов не использовалось как фикстуры.

Перед дальнейшей проверкой в памяти исходной сцены создан снимок Assets/_Recovery/U1-2SourceBackup.unity. Исходная сцена оставалась загружена с отключённым корнем. Копия U1-2Review открыта аддитивно; её имя исключает запуск slot persistence. HasActiveFarm во время проверки был false. Запись выполнялась только в явно указанные файлы Verification/U1-2. Исходная Prototype на диск не сохранялась.

При восстановлении корня до закрытия копии сработала защита единственного GridSystem (console-cleanup-diagnostic.json). Копия закрыта и удалена; исходный GridSystem включён обратно согласно сохранённому снимку (m_Enabled: 1). Исходный корень активен, singleton принадлежит Prototype; исходная сцена оставлена в Edit Mode с прежним dirty-флагом. Снимок несохранённой сцены оставлен для восстановления. Это диагностическое предупреждение процедуры, не ошибка плодоношения.

## Проверки и ограничения

- Скрипты, Editor-команда и подготовленные тесты скомпилированы Unity. Финальная Console после повторной компиляции: ошибок нет, одно предупреждение WebSocket инструмента MCP (console-final.json). Состояние Editor — state-final.json.
- OrchardVarietyTests: три сценария для смеси деревьев/выбора/таймеров, занятой клетки и старого apple_tree, полного инвентаря/повторного входа. Подготовлены, НЕ запускались.
- Автотесты, Verification/Verify-Scripts.ps1, сборка Player и performance-прогон не выполнялись по AGENTS.md.
- Автоматическую пересериализацию ProjectSettings сохранено отдельной копией, исходный файл восстановлен: изменение настроек не входит в U1-2. Прежние незакоммиченные правки пользователя сохранены.
