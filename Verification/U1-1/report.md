# U1-1 — коровы, молоко и коровник

Реализовано 12.11.2026 по отдельному запросу пользователя, раньше планового окна 13–15 ноября. Unity 6000.6.4f1, Built-in. Автотесты не запускались: закрытие U1 ещё впереди.

## Игровой результат

- В категории животных рынка доступны прежняя курица и корова. Корова стоит **40 монет**, ест **1 пшеницу**, через **60 реальных секунд** даёт **1 молоко**. Продажа молока — **28 монет**. Цена/продукт/интервал коровы вынесены в AnimalDefinition, молоко — в ItemDefinition.
- Коровник с отдельным загоном стоит **60 монет**, занимает **9×6 клеток**, содержит до **двух коров**. Общий лимит коров — 8; прежний лимит кур — 8, прежние ID, цены, корм и интервалы кур сохранены.
- Рынок проверяет вместимость и безопасные места всего заказа до списания денег. Коровам присваиваются отдельные instance ID и конкретные `homeBuildingId` / `homeSlot`. Игрок или препятствие в точке доставки блокируют покупку.
- Животные перемещаются возле своих зарезервированных мест в загоне; поворот коровника поворачивает и расположение мест. Места находятся внутри footprint, поэтому другое строительство не может занять их.
- Перенос/поворот коровника перемещает его коров, сохраняя ID и состояние производства. Занятый коровник удалить нельзя; пустой удаляется по прежним правилам возврата половины стоимости.
- Feed и TryCollect защищены от повторного/реентерабельного изменения через UI-события. Переполнение инвентаря не удаляет молоко у животного. Существующий пастух по-прежнему обслуживает кур, без молчаливого расширения на коров.
- Молоко отображается в инвентаре и продаже, коровы — в рынке и справочнике. В справочнике появился выбор «Куры / Коровы». HUD различает количество видов.

## Арт и размещение

Корова использует подготовленный U1-0 prefab с Idle/Walk/Eat. Полная визуальная приёмка движений/анимаций и индикаторов продукции остаётся U1-4.

Выбранный в U1-0 SmallBarn оказался неудачен для игровой интеграции: его дверь — 1,435 м. При равномерном увеличении до 1,98 м здание вместе с загоном требовало 12×8 и плохо размещалось между существующими камнями и фонарями. Этот вариант отклонён без изменения карты.

В итоговом коровнике переиспользована уже откалиброванная модель амбара из `Content/Art/Buildings/storage.prefab`: фактический размер основной постройки около **4,21×3,96×5,70 м**, дверь **1,98 м**. Отдельный деревянный загон входит в общий footprint 9×6. Runtime defaults находятся в `Resources/FarmContent/Cow.asset`, `Milk.asset`, `Barn.prefab`; сцена получает их через существующие системы без нового полного запекания.

Сплошной коллайдер соответствует только самому зданию. Двор и декоративное ограждение не превращаются в большой непрозрачный для выбора короб: к корове можно обратиться снаружи загона. Проверка размещения учитывает рельеф и запрещает постройку на заметно неровном участке. Рабочий пример размещения в неизменённой карте: клетка **(-6, -8)**, поворот **90°**.

## Сохранения

Формат — **v13**. Добавлены поля дома/места животного, прежние имена полей и ID кур не менялись. Capture/Restore сохраняют оба вида. Валидация использует загружаемый снимок построек, проверяет принадлежность коровы конкретному коровнику, слот, положение, занятость сетки и отдельные лимиты видов. Неизвестные виды и потерянный дом не отбрасываются молча при штатной загрузке.

Пути чтения v1–v12 сохранены. Старым курам не нужен новый дом; их прежние координаты, ID и таймеры остаются допустимыми. Загрузка реального контрольного v12 без животных выполнена; сценарий старого v12 с курами подготовлен для финального suite U1 и пока не выполнялся.

## Короткая целевая проверка

Использована временная копия Prototype под именем U1-1Review. Bootstrap запускает файловую persistence только в сцене с именем Prototype, поэтому здесь `HasActiveFarm` оставался false. Контрольные данные писались исключительно в `Verification/U1-1`. Временные деньги (500) и пшеница (8) выданы диагностически; естественный темп заработка не проверялся.

Действия задавались отдельными командами компонентов через Unity MCP в Play Mode, без автоматического сценария/assertions и без имитации полноценного прохождения с клавиатуры. Для осмотра интерфейсов окна открыты непосредственно: обычный вход через меню намеренно заблокирован отсутствием активного пользовательского слота в этой изолированной сцене.

| Действие | Наблюдение | Данные |
|---|---|---|
| Построить коровник | Успешно на исходной карте; 500 → 440 монет | `manual-place.json` |
| Купить корову через FarmMarket.Checkout | Один экземпляр, 440 → 400; корректный дом/слот | `manual-purchase.json` |
| Взаимодействовать у загона | Кормление успешно, пшеница 8 → 7 | `manual-feed.json` |
| Дождаться реального интервала | У коровы готов один продукт, timestamp не ускорялся | `manual-move-save.json` |
| Повернуть коровник 90° → 270° | Та же корова, тот же ID дома, таймер и готовое молоко | `manual-move-save.json` |
| Сохранить и перезапустить Play Mode | v13 записан и загружен, ID/продукт восстановлены | `review-v13.json`, `manual-load-after-play-restart.json` |
| Удалить занятый коровник | Отказ с объяснением, животное остаётся | `manual-remove-occupied.json` |
| Собрать молоко | В инвентаре ровно 1 молоко | `manual-collect.json` |
| Повторить TryCollect и продать молоко | Повторный сбор false/0; продажа +28, баланс 428, молоко 0 | `manual-sale.json` |
| Открыть контрольный файл v12 | Загрузка успешна, исходник не менялся | `manual-v12-load.json` |

Обнаруженное обрезание подписи компактных переключателей справочника исправлено и повторно просмотрено.

## Отложено до закрытия U1

Подготовлен `CowIntegrationTests.cs`: совместимость v12 с курами, отсутствие списания при отсутствии/заполнении коровника, реентерабельный сбор, сохранение ID/производства после переноса и JSON-восстановления. **Эти тесты не запускались.** Также не выполнялись Verify-Scripts, полный regression suite, длительное прохождение, Player build и нагрузочные измерения.

Финальная Console проверена отдельно; итоговые ограничения визуальной приёмки животных остаются U1-4. Временная сцена закрыта, исходная Prototype возвращена без сохранения игровых изменений. Ранее существовавшие незакоммиченные изменения сохранены.
