# P0-1 — Земля и физическая плоскость

Выполнено 20 октября 2026. Unity 6000.6.4f1, `Assets/_Game/Scenes/Prototype.unity`.

## Результат

В исходной сцене верх всех девяти `Ground Visual` уже находился на Y = 0 после предыдущего исправления. Теперь это явный инвариант: выравнивание использует Y = 0, а не потенциально смещённый `Collider.bounds.max.y`. Повторный MVP upgrade обрабатывает также существующие модели земли.

`GroundAlignmentValidator.cs` автоматически проверяет ферму при сохранении сцены. Он обнаруживает разрыв между землёй и физической поверхностью, наклон верхней грани, отсутствующую модель/коллайдер, trigger вместо поверхности и включённые коллайдеры внутри декоративной земли. Для неактивных секторов проверяется геометрия `BoxCollider`, поскольку их физический `bounds` пуст.

Ноги персонажа ранее выравнивались по расширенным габаритам анимации. Измерение реальных вершин выявило зазор около 0,058 unit. Компенсация теперь использует `SkinnedMeshRenderer.BakeMesh` с учётом масштаба импортированного FBX и `CharacterController.skinWidth`. В сцене изменена только высота `Nolant Visual`: −1,0223727 → −1,080319. Остальные прежние изменения проекта сохранены.

## Проверка

| Объект | Результат |
|---|---|
| Девять чанков | Верх видимой земли и физических поверхностей: Y = 0 |
| Персонаж в Play Mode | `isGrounded = true`; низ капсулы ≈ 0,08 при `skinWidth = 0,08`; подошвы ≈ 0,000042 |
| Курица | Низ лап: Y = 0; проверен также при плавном перемещении |
| Дом, склад, торговая стойка, клумба, курятник | Низ моделей и коллайдеров: Y = 0 при поворотах 0°, 90°, 180°, 270° |
| Тени | Проверены на земле в Play Mode; парные кадры при одинаковой камере с тенями и без них различаются на 50 530 пикселей с порогом 12 суммарных RGB уровней |

- EditMode: **19/19**; PlayMode: **27/27**.
- `Verification/Verify-Scripts.ps1`: синтаксис, сборки и доменные проверки пройдены. Его строка `NOT RUN` описывает ограничения самого скрипта; Unity-тесты и рендеринг дополнительно выполнены в подключённом редакторе.
- Ошибок компиляции нет. Проверка Play Mode выполнялась в временной копии сцены с другим именем, без загрузки пользовательского сохранения; копия удалена. Открыта исходная `Prototype.unity`, Play Mode выключен.
- Длительный 30-минутный проход из критерия выхода всей Phase 0 здесь не выполнялся.

## Использование

`Tools → My Little Farm → Ground → Validate Active Scene` выводит нарушения в Console, не меняя геометрию.

`Tools → My Little Farm → Ground → Align Visuals To Y=0` выравнивает модели земли и ноги персонажа, поддерживает Undo. Физические коллайдеры команда не передвигает: их смещение выводится как отдельная проблема. После ручного исправления нужно сохранить сцену.
