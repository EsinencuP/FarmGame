# RC-06 · Яблочный пресс

Пресс доступен на первой странице каталога строительства. Он занимает 2×2 клетки и стоит 80 монет. Для одной партии нужно 3 яблока. Через 60 реальных секунд игрок вручную забирает 1 сок. Сок продаётся за 65 монет. Журнал показывает следующий шаг и отмечает первую продажу в текущем слоте.

## Windows Player

Проверка проведена в Unity 6000.6.4f1 на отдельном профиле `USM-RC06-Review`. Диагностический инструмент выставлял позиции игрока и отправлял команды через Unity Input System. Яблоки и сок созревали в реальном времени.

- Посадил яблоню, собрал 3 яблока и продал их за 54 монеты. Кошелёк вырос с 50 до 104. Покупка пресса оставила 24 монеты. Для партии собрал следующие 3 яблока. [Каталог](Player/press-catalogue.png).
- Во время производства удаление пресса было заблокировано. Перенёс пресс с клетки (1, 1) на (0, 1). ID постройки и срок готовности сохранились. Во втором слоте партий не было. Возврат в первый слот восстановил ту же партию. [Партия в работе](Player/production-running.png).
- При выходе оставалось 46 секунд до готовности. Автосохранение v12 содержало партию, а после перезапуска она была готова. Для проверки переполнения на копии довёл счётчик сока до существующего предела `int.MaxValue`. Партия осталась в прессе. Освободил инвентарь, забрал один сок, повторный сбор количество не увеличил. [Готовый сок](Player/production-ready.png) · [Заполненный инвентарь](Player/press-full.png).
- Продажа сока подняла баланс с 24 до 89 монет. Повторное нажатие не начислило ещё 65. Журнал показал выполненную цель, после загрузки она осталась выполненной. [Сок на рынке](Player/juice-product.png) · [Журнал](Player/first-sale-goal.png).
- Существующую копию v11 загрузил в третьем слоте. Производство и цель первой продажи были пустыми. Ручная запись создала v12. Действующие ветки миграции старых форматов сохранены в коде. В этом проходе из старых форматов загружал v11.

Сборка Windows x64 прошла без ошибок компиляции. Автотесты отложены до закрытия крупной фазы согласно `AGENTS.md`.
