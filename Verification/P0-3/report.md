# P0-3 — масштаб и новый основной персонаж

21 октября 2026 · Unity 6000.6.4f1 · сцена Prototype.

P0-3 выполнен. Дополнительный запрос на полную замену персонажа включён в этот этап: основной персонаж теперь **Kevin Iglesias Human Basic Motions FREE**, с настоящими отдельными анимациями ходьбы, бега, спринта и прыжка.

## Итог

- 1 клетка = 1 Unity unit. Рост Kevin в начальной Idle — 1.8; капсула CharacterController 1.8×0.6, skinWidth 0.03, стоящий root Y=0.93. Подошвы исходной стойки совпадают с Y=0. Движение остаётся на CharacterController.
- Двери дома, склада и курятника — 1.98 = 1.8×1.1. Модели масштабируются равномерно. Исходный курятник имеет только маленький лаз с заслонкой: с обратной стороны добавлена отдельная служебная дверь 0.86×1.98, рама, крепления, ручка и две ступени. Лаз остаётся маленьким.
- Footprint пересмотрены под геометрию, а BoxCollider строится по renderer bounds в локальных координатах здания. Сетка резервирует весь footprint; коллайдер повторяет фактический размер внешней модели.
- Клумба: деревянный короб 0.9×0.9, земля и пять настоящих цветков Nicrom вместо травы.
- Сохранения v7 поддерживают прежние footprint. Миграция сохраняет ID/стоимость зданий, ищет свободное место около исходной позиции, сохраняет остальной контент. Если места нет, отказывает до изменения игровой фермы и входного снимка.

| Постройка | Прежний footprint | Новый footprint | Итоговые bounds X×Y×Z |
|---|---|---|---|
| Дом | 2×2 | 7×6 | 6.4429×4.9299×5.6477 |
| Склад | 2×1 | 5×6 | 4.2116×3.9600×5.6960 |
| Рынок | 1×2 | 8×5 | 7.1758×3.0000×4.0193 |
| Курятник | 2×2 | 3×5 | 2.7738×3.9213×4.6750 |

Сырые замеры: [metric-measurements.txt](metric-measurements.txt). Размеры включают выступы крыши, рамы и ступени. У рынка задана общая высота 3; дверного полотна в этой модели нет. Физический коллайдер зданий остаётся сплошным: вход внутрь не добавлялся.

## Kevin и управление

Использован уже установленный мужской demo Humanoid из Human Basic Motions FREE 2.4.2. Импортированная библиотека сохранена. Игровой prefab `Assets/_Game/Content/Character/HumanPlayerVisual.prefab`, контроллер `KevinLocomotion.controller`, корень в сцене — `Character Visual`. Старый Nolant в сцене заменён; его исходный пакет не удалялся.

Подключены **34 различных in-place клипа**: 8 Walk, 8 Run, 5 Sprint, две Idle с двумя переходами, два поворота, четыре фазы прыжка/падения/приземления, Talk и две позы пальцев отдельным маскированным слоем. Root motion выключен. Нет подмены бега ускоренной ходьбой. AlwaysAnimate устраняет зависание offscreen-позы. Жест Talk запускается и из обычной, и из расслабленной Idle.

| Клавиши | Действие |
|---|---|
| WASD | Ходьба относительно камеры, 2.2 units/s |
| Shift | Бег, 4.5 units/s |
| Shift + Left Ctrl | Спринт, 6.5 units/s; назад — Run |
| Left Alt + WASD | Направленный шаг/бег с ориентацией корпуса по камере |
| Space | Прыжок |
| G стоя | Жест Talk, движение прерывает его |
| E / взаимодействие мышью | Короткий хват пальцами вместе с прежним действием |

Внешность изолирована от физики и игровых систем. Замена материалов либо последующий Humanoid retarget описаны в [CharacterAndBuildingScale.md](../../Docs/Art/CharacterAndBuildingScale.md). Специализированных движений мотыгой в библиотеке нет; поза пальцев их не заменяет.

![Контрольные позы контроллера](character-sheet.png)

Контрольный лист — 15 выборок реального Animator Controller в изолированной preview-сцене; для корректного пакетного Edit Mode рендера позы запечены во временные меши. Это статические выборки, не видеозапись игрового процесса. Код: [CaptureCharacter.cs.txt](CaptureCharacter.cs.txt), [CaptureScale.cs.txt](CaptureScale.cs.txt).

Отдельно запущена копия Prototype в Play Mode: проверены живой Idle и реальный `HumanM@Sprint01_Forward` с весом 1. В копии отключён ввод для контролируемого кадра; изменения камеры/параметров Animator не сохранялись. Копия имела отдельное имя, поэтому автозагрузка и автосохранение Prototype не запускались. После проверки исходная Prototype открыта в Edit Mode, временная сцена удалена.

## Проверки

- EditMode: **33/33**, [JSON](editmode-results.json).
- PlayMode: **34/34**, [JSON](playmode-results.json).
- C# 9 syntax/assembly ownership: 99 скриптов; чистые grid/building/economy проверки — 510726 assertions. [Лог](script-checks.txt).
- Все пять реальных строительных prefab проверены при 0/90/180/270°: основание Y=0, геометрия внутри footprint, центр и размер коллайдера совпадают с bounds. Дополнительно проверен повёрнутый родитель с неравномерным масштабом.
- Валидный Humanoid Avatar, рост 1.8, 34 различных клипа без [RM], реальные кости вне T-pose; Walk Left → Run → Sprint → relaxed Idle → Talk. Реальный прыжок проходит takeoff/rise/fall/land и возвращает CharacterController на землю.
- Миграция v6 увеличивает дом с обходом посева, сохраняет ID/деньги/входной снимок; нехватка места отклоняется атомарно. Отдельный v4 файл без terrain metadata проходит дисковую загрузку с повторной валидацией и сохраняет Dirt.
- C# compilation errors не обнаружены. Во время проверки встречались сообщения импортера `Blender could not be found` для .blend-исходников; проверенные персонаж, здания и цветы загружаются из сохранённых prefab/FBX и отображаются. Наличие Blender не исправлялось в рамках P0-3; финальная Console после перезагрузки домена не содержит ошибок.

Проверки использовали изолированные тестовые сцены и временные файлы. Пользовательские сохранения не открывались и не переписывались. Длинный 30-минутный playtest и измерения производительности не выполнялись. Ранее существовавшие изменения рабочего дерева сохранены; весь Git diff не относится к этому этапу.

Roadmap и AI-контекст обновлены. P0-4 не запускался; отметка P0-6 оставлена для отдельной актуализации и итоговой проверки по очереди, с пояснением о уже выполненной замене анимаций.
