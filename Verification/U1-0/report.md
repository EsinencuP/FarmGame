# U1-0 — подготовка к университетской версии

12 ноября 2026. Unity 6000.6.4f1, Built-in. Исходный код — commit `9284cfb`, с сохранением уже существовавших незакоммиченных изменений.

## Выполнено

- Инвентаризация моделей, материалов, иконок и фактических клипов импортированной коровы через подключённый Editor.
- 20 сохраняемых визуальных префабов, восемь новых прозрачных Sprite-иконок, Cow.controller и три клипа. В игровые каталоги ничего не добавлено.
- Новые стабильные ID и карта интеграции, включая ограничения SaveSystem, шесть quick-slots и отдельную реализацию пресса.
- Три побайтовые контрольные копии v12 из профиля USM-RC06-Review. Список, происхождение и SHA-256: [V12/manifest.json](V12/manifest.json). Настоящие пользовательские фермы не использованы.

Основной отчёт: [Docs/Art/U1Preparation.md](../../Docs/Art/U1Preparation.md). Данные ассетов: [U1AssetManifest.json](../../Docs/Art/U1AssetManifest.json).

## Просмотр

[Контактный лист выбранных ресурсов](art-contact-sheet.png), [13 инструментов-кандидатов](tools-contact-sheet.png). Отдельные кадры находятся в [Previews](Previews).

Модели и три фиксированные позы коровы просмотрены в изолированных preview scenes. Исправлены импортный масштаб коровы, направление наклона головы Eat и опора кормушки. Мельница выбрана среди трёх кандидатов по силуэту; готовая мотыга обнаружена по снимкам, а не по общему имени файла.

Инвентаризация геометрии и ссылок: [prepared-inventory.json](prepared-inventory.json). Активная Prototype осталась в Edit Mode без dirty-флага, сцена не сохранялась. Существующие импортные файлы, исходные шесть культур и игровые ScriptableObject-определения не менялись.

Unity при сохранении новых ассетов автоматически пересериализовала ранее чистый `ProjectSettings/ProjectSettings.asset`. Сериализованная копия сохранена в `projectsettings-editor-reserialized.txt`, исходное содержимое восстановлено из заведомо чистого исходного состояния. Настройки проекта намеренно не менялись.

## Проверки и ограничения

Проверены компиляция/Console, сохранённые ресурсы, материалы, масштаб и фиксированные изображения. Итоговый Console: [console-final.json](console-final.json). Полный цикл анимаций, движение животных, хват инструмента, дверные проёмы и footprint принимаются при внедрении U1-1–U1-7.

Ни автоматические тесты, ни Verify-Scripts, ни Play Mode, ни сборка, ни загрузка/миграция сохранений не выполнялись. Три оригинала v12 не покрывают посевы, животных и незавершённые партии; это явно отмечено для финальной приёмки U1. Старые остановленные тестовые прогоны не возобновлялись.
