Задача растений закрыта: для всех шести текущих культур созданы отдельные префабы ростка, средней и зрелой стадии в `Assets/_Game/Content/Art/CropStages`. ## Что заменить

- Растения моркови, картофеля, огурца и кукурузы: в проекте есть продукты/трава, но нет подходящих полноценных растений. Сейчас используются небольшие зелёные заглушки с отдельным маркером зрелости. Нужны статичные low-poly растения с основанием на Y=0, без физических коллайдеров, согласованные с клеткой 1×1. Для корнеплодов урожай остаётся под землёй; кукурузе нужны листья и початки. Не назначать продукты или декоративную траву во все стадии.
- Nolant Run и Jump/airborne/landing: установлены только `metarig|Idle` и `metarig|Walk`. Подбирать совместимые с существующим скелетом клипы, без root motion. Текущие частота Walk при беге и удержание нейтральной позы в воздухе — временные представления, не полноценные Run/Jump.
- Размеры дверей дома/склада: текущие высоты приведены к каталогу, коллайдеры — к модели. Существующие footprint сохранены. Для окончательного красивого масштаба предпочтительны компактные модели, рассчитанные на эти клетки, а не дальнейшее растягивание исходных крупных зданий. Проверить направление входа после подбора модели.

## Предлагаемая первая версия: три культуры

Рекомендация — пшеница, томат и капуста. Это предложение, каталог пока содержит прежние шесть культур, ID/экономика/сохранённые посевы сохранены.

| Культура | Уже имеющаяся зрелая модель |
|---|---|
| Пшеница | `Assets/Pandazole_Ultimate_Pack/Pandazole Farm Ranch Pack/Prefabs/Env_Wheat.prefab` |
| Томат | `Assets/LowPolyFarmLite/Prefabs/TomatoPlant_01.prefab` |
| Капуста | `Assets/LowPolyFarmLite/Prefabs/Cabbage_01.prefab` |

Плюсы трёх: меньше UI и настроек, три различимых силуэта, зрелые модели уже на диске, проще проверять рост/размеры/экономику. Для ранних стадий достаточно общей маленькой рассады и увеличенного растения без урожая; отдельная сложная система анимации растений не нужна.

Минусы: меньше разнообразия; капуста требует своего определения и предметов вместо одного из текущих видов; сокращение затрагивает быстрые слоты, подсказки, стартовый инвентарь и тесты, рассчитанные на шесть культур. Сохранённые старые культуры нельзя молча удалить или переименовать в капусту. При следующем проходе выбрать между совместимым переходом и явно согласованной новой игрой.

Оставлять шесть ради количества сейчас нецелесообразно: четыре зрелых растения всё равно потребуют новых ассетов. До отдельного решения держать заглушки, не добавлять ещё культуры. Если выбирать бесплатные пакеты позже, проверять бесплатность, лицензию, Built-in pipeline и совместимость визуального стиля до импорта.
