# U1-0 — арт, идентификаторы и точки интеграции

Выполнено 12.11.2026 для университетской версии. Это подготовка ресурсов и договорённостей, а не реализация коров, груши или новых производственных систем.

Дополнение U1-1 от 12.11.2026: корова подключена к игре. Для игрового коровника вместо крупного SmallBarn выбран существующий метрический амбар с дверью 1,98 м; итоговый ресурс — `Resources/FarmContent/Barn.prefab`, footprint с отдельным загоном 9×6. SmallBarn ниже остаётся сохранённым кандидатом подготовки U1-0. Подробности и проверка — `Verification/U1-1/report.md`.

Основной план: `Docs/MyLittleFarm_UniversityDemo_Plan.md`. Машиночитаемый список: `Docs/Art/U1AssetManifest.json`. Результаты осмотра Unity: `Verification/U1-0/source-inspection.json` и `prepared-inventory.json`. Изображения: `Verification/U1-0/Previews/` и `art-contact-sheet.png`.

## Результат

- Созданы **20 визуальных префабов**, три клипа и Animator Controller коровы; ресурсы ещё не подключены к игровым каталогам.
- Добавлены восемь недостающих иконок; существующие изображения не заменены.
- Сохранены три побайтовые копии диагностических сохранений v12 с SHA-256. Настоящие пользовательские фермы не читались и не изменялись.
- Зафиксированы новые ID и все основные ограничения систем, которые необходимо изменить в U1-1–U1-7.
- Автотесты, Play Mode, миграции и загрузка сохранений не запускались. Текущая сцена Prototype не сохранялась и осталась без dirty-флага.

## Выбранный визуальный стандарт

Одна клетка — один метр; персонаж — 1,8 м. Built-in, матовые low-poly формы, существующие цветные материалы. Корова — визуальный эталон семейства животных; постройки используют существующие Quaternius-ресурсы с умеренной насыщенностью. Статические корни располагаются по основанию геометрии; у инструмента pivot расположен в месте хвата. Плод дерева отделён от кроны, чтобы существующий TreeView мог включать его только при готовности.

Все новые префабы лежат в `Assets/_Game/Content/Art/UniversityDemo/`. В них нет игровых компонентов и коллайдеров; исключение по компонентам — Animator коровы. Коллайдеры, загоны, footprint, кнопки и производственные правила добавляются соответствующими системами при интеграции. Это позволяет не менять игровую сцену на подготовительном этапе.

### Анимации

У исходной коровы шесть клипов: `Armature|Death`, `Idle`, `Jump`, `Run`, `Walk`, `WalkSlow`. Их исходные loop-флаги выключены. Для проекта созданы отдельные копии Idle и Walk с loop; исходный FBX и его importer не менялись. Eat создан на основе Idle с авторским наклоном головы и мягким жевательным движением. Controller использует `Speed` и `Eating`, root motion выключен.

В Edit Mode просмотрены фиксированные позы Idle, Walk, Eat. Полный цикл, переходы и скорость шага принимаются в U1-1/U1-4; наличие клипа не означает завершённую игровую анимацию. У деревьев и стадий растений готовых клипов нет и они не нужны для роста: смена префабов и будущее колыхание управляются игровыми системами.

Готовой курицы в выбранном Farm Animals FBX-наборе нет. Текущая процедурная курица остаётся игровой до U1-4. Конкретный путь её замены: авторский low-poly префаб с отдельными головой, крыльями и ногами, три простых клипа Idle/Walk/Eat, без поиска внешнего сервиса или нового AI-пакета. Это отдельный ресурс U1-4, не скрытая зависимость коровы.

## Стабильные ID

ID ниже **зарезервированы**, но ещё не зарегистрированы в runtime. Одинаковая строка допустима в разных реестрах (например дерево `pear` и предмет `pear`), но не означает один объект.

| Реестр | Новые ID | Существующие ID, которые сохраняем |
|---|---|---|
| Вид животного | `cow` | `chicken`; существующие instance ID `chicken_…` |
| Дерево | `pear` | `apple` |
| Культура | `strawberry`, `pumpkin` | `carrot`, `potato`, `wheat`, `tomato`, `corn`, `cucumber`, в прежнем порядке |
| Предмет | `milk`, `pear`, `pear_sapling`, `apple_sapling`, `flour`, `cheese`, `strawberry_seed`, `strawberry`, `pumpkin_seed`, `pumpkin`, `hoe` | Все нынешние семена/урожай, `apple`, `egg`, `apple_juice`; корм — прежний `wheat` |
| Постройка | `barn`, `mill`, `cheese_dairy`, `feeder` | `house`, `storage`, `market`, `coop`, `flowerbed`, `apple_press`, весь декор |
| Рецепт | `wheat_to_flour`, `milk_to_cheese`, `apple_to_juice` | У текущего пресса ID рецепта отсутствует; `apple_to_juice` обозначает сохранение его прежнего процесса |
| Визуальные варианты инструмента | `tool_hoe_0`, `tool_hoe_1`, `tool_hoe_2` | Один инструмент `hoe`, уровни прежнего `toolUpgradeLevel` 0/1/2 |

`apple_sapling` нужен для будущего единого выбора саженцев, а не для переименования `apple` в сохранениях. В U1-2 отдельно сохранить/мигрировать прежнюю доступность посадки яблони; новый пункт магазина не должен молча отнимать старую возможность. Цены и длительности новых рецептов в U1-0 не фиксируются: их согласует баланс U1-1–U1-7. Числа существующего пресса остаются прежними до явного изменения баланса.

Instance ID построек/животных, ID слота, ID предложения рынка и ID контентного определения — разные сущности. Рыночный заказ получает отдельный сохраняемый instance ID и срок; нельзя награждать по одному только ID товара.

### Сохранения — обязательные изменения перед приёмкой U1

`Core/SaveSystem.cs` сейчас допускает quick-slot только 0–5 (около строки 379), treeId только равный единственному TreeDefinitionId (около 514), animal.definitionId только единственного вида (около 534). Партии отдельно Capture/Restore/Validate через ApplePresses. Без этих изменений новая ферма может выглядеть правильно, но отклоняться загрузчиком.

`SaveData` уже хранит `treeId`, `animal.definitionId` и instance ID постройки, поэтому расширять нужно правила и дополнительные состояния, а не переименовывать старые поля без миграции. В дальнейшем потребуются новые данные regrow, склада, назначений слотов, общих партий, кормушек, загонов и заказов. Версии повышать по реально внедряемой схеме, начиная с v12; U1-0 формат не меняет. Отсутствующие новые поля старого файла означают безопасные пустые значения, существующие деньги/инвентарь/животные/партии сохраняются.

## Воспроизведение и границы проверки

Команда Unity: `Tools / My Little Farm / University / Prepare U1-0 Art`. Запускается только явно в Edit Mode, сохраняет существующие префабы и назначения, не меняет игровые каталоги, сцену или пользовательские сохранения. Меши/материалы/клипы сохраняются как обычные ассеты; построение не требуется в Player.

Выполнены компиляция/Console, осмотр геометрии, материалов, размеров и фиксированных поз в изолированной preview scene. При осмотре исправлены импортный масштаб коровы, направление наклона головы Eat и положение кормушки на земле. На стадии выбора мельницы отвергнуты открытые ветряки в пользу узнаваемой башенной модели; мотыга определена по снимкам 13 кандидатов.

Итоговые игровые масштабы дверей, размеры footprint, движение коровы, привязка инструмента к руке и чтение иконок с игровой камеры принимаются при реализации зависимых пунктов. В текущем шаге не делались игровой прогон, performance-test, сборка или автоматические проверки. Полноценная готовность игровых функций этим отчётом не заявляется.

## Интеграция груши U1-2 — 12.11.2026
