# Аудиосистема My Little Farm

Система подготовлена 22.10.2026. Файлы музыки и новых эффектов ожидаются от пользователя; звуки не генерировались и не скачивались. Сохранена существующая петля дождя.

## Подключение файлов

1. Импортировать файлы в `Assets/_Game/Content/Audio/` (можно создать подпапки Music, SFX, Ambience, UI).
2. Выбрать `Assets/_Game/Resources/Audio/FarmAudioCatalog.asset` в Unity Project.
3. В `Cues` найти нужный `id`, раскрыть `clips` и перетащить AudioClip. Сейчас подготовлено 36 идентификаторов. Отсутствующий клип пропускается без ошибок.
4. Для короткого эффекта можно назначить несколько вариантов. Для музыкальной темы массив `clips` является плейлистом: один файл зацикливается, несколько меняются с crossfade и без немедленного повторения того же индекса.
5. Настроить `gainDb`, диапазон высоты `pitchRange`, `cooldown`, `maxInstances` и `priority` (меньшее число — выше важность). У музыкальных/ambient-петель высота фиксирована; pitchRange используется короткими эффектами.
6. Проверять изменения после нового входа в Play Mode. Редактирование каталога на лету не является режимом live preview.

Команда `Tools → My Little Farm → Audio → Prepare Audio System` восстанавливает каналы, добавляет отсутствующие слоты и обновляет UI обеих сцен. Существующие назначения клипов и настройки слотов сохраняются. Редакторская команда не запускает ферму и не обращается к файлам игрока.

## Каналы и настройки

`Assets/_Game/Content/Audio/FarmAudio.mixer`: Master → Music / SFX / Ambience / UI. Экспонированы параметры MasterDb, MusicDb, SfxDb, AmbienceDb, UiDb. Пользовательские уровни 0…1 переводятся в dB через 20·log10; нулевой уровень глушит соответствующие источники. Настройки доступны в главном меню и в паузе: общая громкость, музыка, игровые звуки, окружение, интерфейс, общий mute и звук в фоне.

Изменения применяются и сохраняются кнопкой «Применить». «Назад» отменяет черновик; «Сбросить» меняет черновик до подтверждения. Используется прежний ключ PlayerPrefs `MyLittleFarm.UI.Settings.v1`, прежние volume/mute/backgroundAudio совместимы. Новые уровни по умолчанию: Music 75%, SFX 100%, Ambience/UI 80%, Master 80%. Фокус приложения обрабатывает постоянный аудиосервис, даже когда настройки закрыты.

В сценах остаётся по одному AudioListener на камере. `FarmAudio` создаётся автоматически до загрузки сцены, переживает смену меню/фермы и не создаёт свой listener. Пул коротких эффектов ограничен 20 источниками; дополнительно есть два источника музыки, два окружения и дождь. Когда пул заполнен, более важный эффект может заменить менее важный; есть ограничения повторов. Случайность звука не использует UnityEngine.Random и не меняет случайность игры.

## События

| Слоты | Подключение |
| --- | --- |
| UiHover / UiClick | Кнопки обеих сцен, наведение и выбор с клавиатуры |
| UiOpen / UiClose / UiBack / UiError | Основные окна меню/фермы; неудачная сделка |
| Till / Plant / Harvest | Успешная обработка земли, посадка, сбор |
| Sell / Purchase | Успешные сделки, включая магазин в паузе |
| BuildPlace / BuildMove / BuildRemove / BuildRotate | Строительство, перенос, удаление, поворот |
| TreePlant / AppleHarvest / ChickenBuy / ChickenFeed / EggCollect | Существующие события деревьев и кур |
| RareSeedCollect / SectorUnlock / ToolUpgrade / HouseUpgrade | Тайник, сектор, улучшения |
| Achievement / Save / Load | Достижение, ручное сохранение, успешная загрузка; без звука каждого autosave |
| Footstep / Jump / Land | PlayerAudioEmitter: фактическое движение, прыжок, приземление; шаги не срабатывают при упоре в стену или паузе |
| MusicMenu / MusicFarmDay / MusicFarmNight | Контекст сцены и время суток; переключение с crossfade |
| AmbienceDay / AmbienceNight / AmbienceRain | Дневная/ночная атмосфера, интенсивность дождя |

Контекст дня/ночи обновляется раз в секунду; ночная тема используется с 18:00 до 06:00. Если одна музыкальная тема фермы пуста, используется заполненная вторая. При смене сцен музыка плавно меняется, звуки старого мира останавливаются. Дождь использует исходную погодную огибающую; старый локальный источник не дублирует постоянный сервис. Для замены дождя назначить новый клип в AmbienceRain.

В паузе музыка приглушается (по умолчанию −6 dB), UI остаётся активным, мир и окружающие петли приостанавливаются. Для SFX, которым разрешено звучать из паузы, используется `playWhilePaused`; он включён у покупки/продажи. Переходы и UI не зависят от Time.timeScale.

Для нового события в коде:

```csharp
using MyLittleFarm.Audio;

FarmAudio.Play(SoundId.Harvest, worldPosition);
FarmAudio.PlayAtPlayer(SoundId.ToolUpgrade);
```

Вызов возвращает bool: false означает отсутствие клипа, cooldown, лимит голосов либо запрет паузой. Добавлять новые SoundId следует в конец enum, сохраняя числовые значения уже существующих. После этого запустить Prepare Audio System. Не воспроизводить один и тот же эффект одновременно через существующее событие FarmAction и прямой вызов.

## Импорт и следующая приёмка

Длинную музыку обычно импортировать как Streaming, ambience — Compressed In Memory либо Streaming, короткие частые эффекты — Decompress On Load. Для источников в мире предпочтительно моно; UI/музыка могут быть стерео. Длинным файлам отключить Preload Audio Data при необходимости и включить Load In Background. Точные параметры и память оценивать после получения файлов. Не добавлять положительный gain: исходные уровни оставляют запас по громкости.

После получения файлов нужны прослушивание на реальном выходе, баланс уровней и дальностей, плавность смены треков/петель, pause/resume, смена сцен, mute/focus, сохранение настроек и нагрузка пула. Их нельзя считать проверенными без реальных материалов. Куры idle, новые виды животных, поверхность шагов и другие будущие события потребуют своих клипов/дополнительных идентификаторов; текущий каталог расширяется без изменения системы проигрывания.

Автоматические тесты и Verify-Scripts отложены до закрытия крупных фаз согласно AGENTS.md. Подготовленная система не закрывает Phase 2/3 или весь P3-3.
