# Порядок проверок

По прямому указанию пользователя от 21.10.2026 автоматические тесты запускаются только при финальном закрытии крупных фаз roadmap: Phase 0, Phase 1, Phase 2 и далее.

- Не запускать полные или выборочные тесты после отдельных пунктов P0-4, P0-5, P1-1 и т. п. Не запускать `Verification/Verify-Scripts.ps1` внутри фазы: он тоже выполняет автоматические проверки и assertions.
- До закрытия фазы ограничиваться проверкой компиляции/Console и короткими целевыми визуальными или ручными проверками изменений. Не заменять отложенный test suite другим тестовым прогоном.
- Тестовые сценарии можно подготовить вместе с изменениями, но выполнять их следует в конце соответствующей крупной фазы.
- Отдельный явный запрос пользователя на более ранний прогон имеет приоритет. Не запрашивать подтверждение этого правила при каждой задаче.

Активный roadmap: `Docs/MyLittleFarm_RoadToRelease.md`. Контекст проекта: `Docs/AI/UnityProjectContext.md`. Сохранять существующие незакоммиченные изменения рабочего дерева.
