# My Little Farm: UI-набор (low-poly)

## Что внутри
| Папка / файл | Содержимое |
|---|---|
| `icons/01_menu` … `icons/07_build` | 107 отдельных иконок SVG 64×64, разложены по категориям |
| `00_all_icons_sheet.svg` | все иконки на одном листе с подписями |
| `screens/` | 12 макетов экранов 1920×1080 + UI Kit |
| `MyLittleFarm_UI_Icons_and_Screens.pdf` | всё вместе в PDF (13 страниц) |
| `_generator/` | Python-скрипты, которые генерируют все файлы (`python3 build_all.py`) |

## Экраны
00 UI Kit · 01 Главное меню (кнопка СТАРТ) · 02–04 Настройки (Звук / Графика / Управление) ·
05 Загрузка сохранений · 06 Диалог удаления сейва · 07 Экран загрузки · 08 HUD ·
09 Инвентарь · 10 Магазин / Каталог фермы · 11 Пауза

## Импорт в Figma
1. Перетащите `.svg` прямо в Figma: всё импортируется векторными слоями.
2. Названия слоёв берутся из `id`: `btn_start`, `quickbar`, `save_slot_1`, `icon_coin` и т.д.
3. Шрифт **Nunito** (есть в Figma по умолчанию). В PDF он может отобразиться
   системным шрифтом, если Nunito не установлен на компьютере.
4. Иконки удобно превратить в компоненты: выделить → `Ctrl/Cmd + Alt + K`.

## Стиль
* Каждая форма собрана из треугольных граней, освещённых сверху слева, как деревья и камни в игре.
* Палитра взята из сцены: трава `#5FB236`, листва `#8FD14F`, дерево `#A0673A`,
  фонари `#F29B38`, вода `#2F9FA8`, небо `#6EC1F0`, панели `#FFF4DC`.
* Панели плоские, крупные, с округлыми карточками (GDD §2.2, §8).
